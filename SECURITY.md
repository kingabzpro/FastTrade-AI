# Reporting a vulnerability

Please report suspected vulnerabilities privately using the contact form at [abidaliawan.com](https://abidaliawan.com/) and include “FastTrade AI security” in the message. Please do not open a public issue for an unpatched vulnerability.

Describe the affected version, the impact, and steps to reproduce. Do not include credentials or sensitive personal data in the initial report; use the form to request a suitable private channel for sensitive details. The maintainer will review the report and follow up using the contact details provided.
